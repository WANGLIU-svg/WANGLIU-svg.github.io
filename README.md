# Picturesque Scenery — Personal Website

A responsive, editorial-style personal website for Picturesque Scenery.

## Structure

```text
picturesque-personal-website/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── README.md
```

## Run

No build tools are required.

1. Open `index.html` in a modern browser.
2. For local development, you can also use VS Code Live Server or any static HTTP server.

## Customize

- Main content: `index.html`
- Visual design and responsive layout: `css/style.css`
- Navigation behavior and active section highlighting: `js/main.js`
- Replace the placeholder social links (`href="#"`) with the actual profile URLs when available.

## Notes

The visual hero and project artwork are CSS-generated, so the project works without external image assets.
Google Fonts are loaded remotely; the site falls back to system fonts if they are unavailable.
